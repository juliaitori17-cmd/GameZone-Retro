# 🎮 GameZone Retro

## 📋 Sobre o Projeto

A **GameZone Retro** é uma página HTML criada para representar uma loja de **games retrô**, apresentando jogos, consoles e produtos clássicos.

O projeto foi desenvolvido como parte de um mini desafio de **HTML**, com o objetivo de praticar os principais elementos da linguagem.

## 🎯 Objetivo

Criar uma página simples e funcional utilizando apenas **HTML**, contendo textos, imagem, lista, links e tabela.

## 🛠️ Tecnologias Utilizadas

* HTML5
* Navegador Web

## 📌 Recursos da Página

A página possui:

* 🎮 Título da loja
* 📝 Textos com **negrito** e *itálico*
* 🕹️ Lista de consoles retrô
* 🔗 Link interno para os produtos
* 🌐 Link externo sobre a história dos videogames
* 🖼️ Imagem relacionada a games retrô
* 💰 Tabela com produtos e preços

## 📂 Estrutura

```text
GameZone-Retro/
│
└── index.html
```

## 🚀 Como Executar

1. Baixe ou clone este projeto.
2. Abra o arquivo `index.html`.
3. Execute o arquivo em qualquer navegador.
4. Navegue pela página e confira os produtos.
